САЙТ-ПОРТФОЛИО АКТАНА

Как запустить:
1. Распакуйте ZIP-архив.
2. Откройте файл index.html в браузере (двойной клик).
Интернет нужен только для ссылки на Instagram.

Структура:
index.html     - страница сайта
css/style.css  - стили
js/script.js   - JavaScript
images/photo.jpg - фото для раздела «Обо мне»

JS-функции:
1. Мобильное меню - на телефоне кнопка «Меню» открывает и закрывает навигацию.
2. Проверка формы - проверяет имя, почту (есть ли @) и сообщение (от 5 символов),
   показывает ошибки под полями или сообщение об успехе.
3. Тёмная и светлая тема - кнопка в меню переключает цвета сайта.
4. Фильтр навыков - кнопки «Все», «Технические», «Личные» показывают нужные карточки.
